ValIO is plugin-based: each generator lives in its own assembly and is
registered through `AddAllGeneratorPlugins()`. Twelve plugins ship today,
covering web, mobile, backend, and game engine targets.

## Per-plugin options

Each plugin exposes an `OptionsDescriptor.GetOptionDescriptions()` list. The
Web UI uses it to render a dynamic form; from CLI and config files the same
options are passed under `"options"` in `valio.config.json`. Open each
language card above for the full per-plugin option reference.

The values are also surfaced in Web UI tooltips via
`OptionDescription.DescriptionKey` resource lookups, so every option has both
inline help and a stable documentation anchor.
