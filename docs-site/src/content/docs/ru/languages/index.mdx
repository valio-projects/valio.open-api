## Опции для каждого плагина

Каждый плагин предоставляет список `OptionsDescriptor.GetOptionDescriptions()`.
Веб-приложение использует его для построения динамической формы; в CLI
и файлах конфигурации те же опции передаются в поле `"options"` файла
`valio.config.json`. Полный справочник опций по каждому плагину
открывается из карточек выше.

Эти же значения отображаются во всплывающих подсказках Web UI через
ресурсные ключи `OptionDescription.DescriptionKey`, так что у каждой
опции есть и встроенная справка, и устойчивая ссылка в документации.
