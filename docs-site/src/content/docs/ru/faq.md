## Почему один бинарник CLI, а не генератор для NuGet?

Генераторы исходного кода NuGet работают во время компиляции внутри
проекта потребителя. ValIO ориентирован на OpenAPI — большинству
пользователей нужно один и тот же результат генерации, воспроизведённый
в нескольких репозиториях и на нескольких языках, а не только в одном
C#-проекте. Самостоятельный инструмент лучше подходит для такого
сценария и делает генератор независимым от среды выполнения потребителя.

## Можно ли использовать ValIO офлайн?

Да. CLI и десктопное приложение работают полностью офлайн, если у вас
есть локальная копия OpenAPI-схемы. Веб-приложение обращается к сети
только при вставке URL — загруженные файлы обрабатываются локально.

## Какого размера может быть моя схема?

В веб-приложении лимит на загрузку и получение по URL — 10 МБ. У CLI
жёсткого ограничения нет; разбор OpenAPI происходит в памяти.

## Может ли ValIO записать что-то обратно в мой репозиторий?

ValIO никогда не пишет за пределами каталога, указанного в `--output`.
Веб- и десктоп-приложения никогда не записывают результаты на диск
сервера: Web отдаёт zip-архив прямо в браузер, а Desktop сохраняет
файлы по пути, выбранному вами в нативном диалоге.

## Можно ли использовать сгенерированный код в коммерческих проектах?

Сгенерированный код не несёт лицензионных ограничений со стороны ValIO
и принимает ту лицензию, которую вы выбрали для своего проекта. Сам
ValIO распространяется как открытое ПО — см. файл `LICENSE` в корне
репозитория.
