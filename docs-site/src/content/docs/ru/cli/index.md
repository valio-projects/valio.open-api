`valio` — это единый самодостаточный исполняемый файл, собранный из
`ValIO.Cli`. Этот же бинарник разбирает схемы OpenAPI, запускает
плагины-генераторы и пишет результат как дерево файлов или как
zip-архив.

## Подкоманды

- [`valio generate`](./generate/) — сгенерировать код по OpenAPI-схеме
- [`valio validate`](./validate/) — разобрать схему и вывести её метаданные

## Глобальные опции

- `--lang <код>` — культура интерфейса для сообщений. Принимает `en`,
  `ru`, `de`, `zh-CN`. Также читается переменная окружения `VALIO_LANG`.

## Коды завершения

| Код  | Значение                                  |
|------|-------------------------------------------|
| 0    | Успех                                     |
| 1    | Ошибка разбора, валидации или ввода-вывода|
