`AddAllGeneratorPlugins()` 注册。目前共附带十二个插件，覆盖 Web、
移动端、后端以及游戏引擎等目标。

## 各插件选项

每个插件都对外提供一个 `OptionsDescriptor.GetOptionDescriptions()`
列表。Web UI 据此渲染动态表单；CLI 与配置文件则在
`valio.config.json` 的 `"options"` 字段中传入相同的选项。完整的逐插件
选项参考可通过上方的语言卡片打开。

这些数值同样会通过 `OptionDescription.DescriptionKey` 的资源查找出现
在 Web UI 的工具提示中，因此每个选项既有内联帮助，也有稳定的文档
锚点。
