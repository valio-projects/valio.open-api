## 为什么是单一的 CLI 二进制文件，而不是 NuGet 生成器？

NuGet 源生成器在使用者项目中的编译期运行。ValIO 以 OpenAPI 为核心 ——
大多数使用者希望同一份生成结果能够在多个仓库与多种语言之间复用，而不
仅仅局限于一个 C# 项目。独立的工具更符合这一场景，并能让生成器独立
于使用者的运行时。

## 可以离线使用 ValIO 吗？

可以。只要本地拥有一份 OpenAPI 架构文件，CLI 和桌面应用即可完全离线
运行。Web UI 只在您粘贴 URL 时通过网络获取架构 —— 上传的文件均在
本地处理。

## 我的架构可以多大？

Web UI 将上传文件和远程获取的大小上限设为 10 MB。CLI 没有硬性上限；
OpenAPI 解析在内存中完成。

## ValIO 会写回到我的仓库吗？

ValIO 不会向 `--output` 指定目录以外的任何位置写入数据。Web 与桌面
应用在客户端工作中从不向服务器磁盘写入文件 —— Web 直接把 zip 流
传回浏览器，Desktop 则写入您在原生文件对话框中选择的路径。

## 生成的代码可以用于商业项目吗？

生成的代码不包含来自 ValIO 的任何许可证条款；它会沿用您为自己的项目
选择的许可证。ValIO 本身是开源软件 —— 详见仓库根目录下的 `LICENSE`
文件。
