The C# generator emits DTOs and an `HttpClient`-friendly API client per
OpenAPI tag. It's deliberately small on options (just `namespace` and
`nullableReferenceTypes`), but pairs with several host shapes depending on
whether you live inside ASP.NET Core, a console app, or want a non-default
HTTP client.

The pages below pin a few of those host shapes down to **concrete, tested
recipes**: each one gives you the exact `valio.config.json`, the file tree
to expect, and a few lines of consumer code so you can sanity-check the
output before wiring it into your service.
