The Java generator emits value classes plus a strongly-typed client per
OpenAPI tag. ValIO's first-class HTTP client is OkHttp 3.x; the
generated DTOs are Jackson-friendly, which means you can pair them
with the JDK 11+ built-in `java.net.http.HttpClient` if you'd rather
not bring in a third-party HTTP library.

The pages below pin those choices to **concrete, tested recipes**: each
one gives you the exact `valio.config.json`, the file tree to expect,
and a few lines of consumer code so you can sanity-check the output.
