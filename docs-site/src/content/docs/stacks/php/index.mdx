The PHP generator targets PHP 8.1+ and emits typed value objects plus a
Guzzle 7-based client. Inside Symfony or any framework that ships
`symfony/serializer`, you can swap the generated `toArray` / `fromArray`
helpers for serializer-driven (de)serialization for a more idiomatic
feel.

The page below pins this down to a **concrete, tested recipe**: an exact
`valio.config.json`, the file tree you should expect, and a few lines of
consumer code so you can sanity-check the output before wiring it into
your Symfony or pure-PHP project.
