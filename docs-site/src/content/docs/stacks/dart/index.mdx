The Dart generator emits null-safe Dart 3 classes plus a thin HTTP
client. The default ships with `package:dio`; the recipe below shows
how to retarget it to the standard `package:http` for the smallest
possible Flutter binary.

The page below pins this down to a **concrete, tested recipe**: an exact
`valio.config.json`, the file tree you should expect, and a few lines of
consumer code so you can sanity-check the output before wiring it into
your Flutter or pure-Dart project.
