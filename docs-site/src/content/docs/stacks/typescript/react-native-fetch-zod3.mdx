## When to use

You're building a React Native app (Expo or bare workflow) and want
generated clients that behave well on mobile networks: every request gets
an `AbortSignal`, retries are driven by TanStack Query rather than the
transport, and there's no axios peer dep to bloat your bundle. Zod 3 is
preferred over Zod 4 here because it has the widest compatibility with
existing React Native libraries (notably some form libs and async-storage
adapters that haven't yet caught up to Zod 4).

## CLI invocation

```sh
valio generate \
  --config ./valio.config.json \
  -p PetstoreApi
```

## valio.config.json

```json
{
  "projects": {
    "PetstoreApi": {
      "language": "typescript",
      "schema": "./openapi/petstore.yaml",
      "outputPath": "src/api/generated",
      "generateModels": true,
      "generateClients": true,
      "options": {
        "transports": ["fetch"],
        "validation": "zod3",
        "queryWrapper": "tanstack-react",
        "enumFormat": "union"
      },
      "fileOrganization": {
        "separateModels": true,
        "separateClients": true,
        "modelsPath": "models",
        "clientsPath": "api"
      }
    }
  }
}
```

## What gets generated

Zod 3 schemas per model. A `<op>.fetch.ts` transport using the React
Native `fetch` global, accepting an `AbortSignal` for cancellation when
the user navigates away. A `<op>.tanstack-react.ts` hook wires the
transport into `useQuery` so you get retries-on-reconnect and refetch-on-
app-focus out of the box.

  <TabItem label="Pet.ts">

    ```ts
    // models/Pet/Pet.ts
    import { z } from "zod";

    export const PetSchema = z.object({
      id: z.number().int(),
      name: z.string().min(1),
      tag: z.string().optional(),
    });

    export type Pet = z.infer<typeof PetSchema>;
    ```

  </TabItem>
  <TabItem label="listPets.fetch.ts">

    ```ts
    // api/listPets/listPets.fetch.ts
    import type { Pets } from "../../models/Pets/Pets";

    export async function listPets(
      init?: { signal?: AbortSignal }
    ): Promise<Pets> {
      const res = await fetch("https://api.petstore.example/pets", {
        method: "GET",
        signal: init?.signal,
      });
      if (!res.ok) throw new Error(`listPets failed: ${res.status}`);
      return (await res.json()) as Pets;
    }
    ```

  </TabItem>
  <TabItem label="PetsScreen.tsx">

    ```tsx
    // screens/PetsScreen.tsx
    import { ActivityIndicator, FlatList, Text } from "react-native";
    import { useListPets } from "../api/generated/api/listPets/listPets.tanstack-react";

    export function PetsScreen() {
      const { data, isLoading, refetch, isRefetching } = useListPets();

      if (isLoading) return <ActivityIndicator />;

      return (
        <FlatList
          data={data}
          keyExtractor={(item) => String(item.id)}
          renderItem={({ item }) => <Text>{item.name}</Text>}
          refreshing={isRefetching}
          onRefresh={refetch}
        />
      );
    }
    ```
