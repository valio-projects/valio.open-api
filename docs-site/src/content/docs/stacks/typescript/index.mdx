The TypeScript generator has five orthogonal axes — transport, validation,
query wrapper, mock library, enum format — which multiply out to more than a
hundred valid combinations. The pages below pin a handful of those down to
**concrete, tested stack recipes**: each one gives you the exact
`valio.config.json`, the file tree you should expect, and a few lines of
consumer code so you can sanity-check the output before you wire it into
your app.

If your stack is not listed, mix the [TypeScript reference](/languages/typescript/)
options to taste — these pages are starting points, not the only valid combos.
