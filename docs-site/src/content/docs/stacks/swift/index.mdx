The Swift generator emits `Codable` structs plus a `URLSession`-based
async/await client. There are no third-party dependencies — everything
compiles against the standard library and Foundation, which means the
generated package works in iOS apps, macOS tools, Swift on Linux, and
server frameworks like Vapor.

The page below pins this down to a **concrete, tested recipe**: an exact
`valio.config.json`, the file tree you should expect, and a few lines of
consumer code so you can sanity-check the output before wiring it into
your app.
