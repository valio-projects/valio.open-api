The Kotlin generator emits `@Serializable` data classes plus a
coroutine-based client. ValIO's default HTTP/serialization combo is
OkHttp + `kotlinx.serialization`, but the data classes are
serializer-agnostic enough that you can pair them with Ktor Client when
you need a multiplatform target.

The pages below pin those choices to **concrete, tested recipes**: each
one gives you the exact `valio.config.json`, the file tree to expect,
and a few lines of consumer code so you can sanity-check the output.
