The Python generator has two main axes — `httpxMode` (`async` vs `sync`)
and `validator` (Pydantic v2 today; `msgspec` reserved) — which together
cover most real-world usage. The pages below pin those down to **concrete,
tested recipes**: each one gives you the exact `valio.config.json`, the
file tree you should expect, and a few lines of consumer code so you can
sanity-check the output before wiring it into your app.
