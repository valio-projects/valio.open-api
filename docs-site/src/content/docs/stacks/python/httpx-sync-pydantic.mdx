## When to use

You're writing a CLI, scheduled job, or sync Django view that needs to
call an HTTP API. You want type-safe DTOs without dragging an asyncio
runtime into a codebase that doesn't use one. `httpx.Client` gives you
the same ergonomic API as `AsyncClient`, just without the `await`.

## Required versions

| Component | Version |
|-----------|---------|
| Python | 3.11 (also 3.10 / 3.12 / 3.13) |
| `httpx` | 0.27+ |
| `pydantic` | 2.6+ |

## CLI invocation

```sh
valio generate --config ./valio.config.json -p petstore-sync
```

## valio.config.json

```json
{
  "projects": {
    "petstore-sync": {
      "language": "python",
      "schema": "./openapi.yaml",
      "outputPath": "./src/petstore_client",
      "options": {
        "pythonVersion": "3.11",
        "httpxMode": "sync",
        "validator": "pydantic",
        "rootModule": "petstore_client"
      },
      "fileOrganization": {
        "separateModels": true,
        "separateClients": true,
        "modelsPath": "models",
        "clientsPath": "client"
      }
    }
  }
}
```

## What gets generated

One Pydantic v2 `BaseModel` per OpenAPI schema, and one `*Client` per
tag built on `httpx.Client`. Operations are plain `def` (no `async`) and
return the typed model directly.

## File tree

```
src/petstore_client/
├── __init__.py
├── models/
│   ├── __init__.py
│   └── pet.py
└── client/
    ├── __init__.py
    └── pets_client.py
```

## Example

<Tabs syncKey="stack-example">
  <TabItem label="pet.py">

    ```python
    from pydantic import BaseModel, ConfigDict, Field


    class Pet(BaseModel):
        model_config = ConfigDict(populate_by_name=True)

        id: int = Field(alias="id")
        name: str = Field(alias="name", min_length=1)
        tag: str | None = Field(default=None, alias="tag")
    ```

  </TabItem>
  <TabItem label="pets_client.py">

    ```python
    from __future__ import annotations

    import httpx

    from ..models.pet import Pet


    class PetsClient:
        def __init__(self, client: httpx.Client) -> None:
            self._client = client

        def list_pets(self) -> list[Pet]:
            response = self._client.get("/pets")
            response.raise_for_status()
            return [Pet.model_validate(item) for item in response.json()]

        def create_pet(self, body: Pet) -> Pet:
            response = self._client.post(
                "/pets",
                json=body.model_dump(by_alias=True, exclude_none=True),
            )
            response.raise_for_status()
            return Pet.model_validate(response.json())
    ```

  </TabItem>
  <TabItem label="cli.py">

    ```python
    # cli.py
    import httpx

    from petstore_client.client.pets_client import PetsClient


    def main() -> None:
        with httpx.Client(base_url="https://petstore.example.com/v1", timeout=10.0) as http:
            client = PetsClient(http)
            for pet in client.list_pets():
                print(f"{pet.id}: {pet.name}")


    if __name__ == "__main__":
        main()
    ```

  </TabItem>
</Tabs>
