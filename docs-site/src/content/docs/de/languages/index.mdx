## Optionen pro Plugin

Jedes Plugin stellt eine Liste `OptionsDescriptor.GetOptionDescriptions()`
bereit. Die Web-UI rendert daraus ein dynamisches Formular; in CLI und
Konfigurationsdateien werden dieselben Optionen unter `"options"` in
`valio.config.json` übergeben. Die vollständige Optionsreferenz pro
Plugin öffnen Sie über die obigen Sprachkarten.

Die Werte erscheinen außerdem in den Tooltips der Web-UI via
Ressourcen-Lookups über `OptionDescription.DescriptionKey`, sodass jede
Option sowohl Inline-Hilfe als auch einen stabilen Dokumentationsanker
besitzt.
