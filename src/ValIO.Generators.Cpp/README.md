# ValIO.Generators.Cpp

The **C++** generator plugin, targeting the **Unreal Engine** HTTP module / UE plugin shape
(`LanguageId = "cpp"`).

- HTTP client: Unreal Engine HTTP. Emits UE-style types and async actions. Options (e.g. module API
  macro, blueprint category, copyright header) — see `Options/`.

Layout: `*GeneratorPlugin.cs`, `Steps/`, `Ast/`, `Services/`, `Options/`.
See the [Developer Guide](../../docs/DEVELOPER_GUIDE.md).
