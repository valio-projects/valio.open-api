# ValIO.Generators.Dart

The **Dart** generator plugin (`LanguageId = "dart"`). Generates null-safe models and a client over the
`http` package.

- HTTP client: `http`. Null-safe. Options (e.g. `packageName`, `anyMapping`) — see `Options/`.

Layout: `*GeneratorPlugin.cs`, `Steps/`, `Ast/`, `Options/`.
See the [Developer Guide](../../docs/DEVELOPER_GUIDE.md).
