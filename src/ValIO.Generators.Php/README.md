# ValIO.Generators.Php

The **PHP** generator plugin (`LanguageId = "php"`). Generates models and a Guzzle-based client (PSR-7).

- HTTP client: Guzzle. Options (e.g. `namespace`, `useHttpClient`, `generateComposerJson`) — see `Options/`.

Layout: `*GeneratorPlugin.cs`, `Steps/`, `Ast/`, `Options/`.
See the [Developer Guide](../../docs/DEVELOPER_GUIDE.md).
